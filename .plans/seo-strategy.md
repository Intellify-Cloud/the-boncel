# SEO Strategy & Implementation Plan

## Executive Summary

The Bond Cellar site uses `jekyll-seo-tag` and `jekyll-sitemap` for basic SEO, but the current configuration has a few high-impact issues that should be fixed before adding advanced markup. This plan focuses first on canonical accuracy, location consistency, useful page metadata, and structured data for the South African home loan market.

---

## Current SEO State Analysis

### What's Working

- **jekyll-seo-tag plugin** configured and generating meta tags
- **Meta viewport** set correctly for mobile
- **Canonical URLs** generated automatically by the SEO plugin
- **Sitemap.xml** generated by `jekyll-sitemap`
- **Structured data** generated automatically by `jekyll-seo-tag`

### Issues Found

- **Canonical domain mismatch** in `_config.yml` - `url` currently points to `https://evohomeloans.co.za`
- **Location mismatch** in `_config.yml` - "Durban/KZN" vs "Cape Town/Western Cape"
- **Title typo** in `_config.yml` - "amd" should be "and"
- **No verified custom social image** for Open Graph/Twitter previews
- **Generic site description** that is too long and not location-consistent
- **Calculator pages lack unique descriptions** and mostly contain embedded iframes
- **No explicit organization/local business schema** for business details
- **Local SEO metadata** lacks a complete source of truth for phone, service area, hours, and profiles

---

## SEO Implementation Plan

### Phase 1: Configuration Fixes (Immediate)

#### 1. Fix Canonical Domain in `_config.yml`

Current:

- `url: https://evohomeloans.co.za`

Should be changed to the real production domain for The Bond Cellar, for example:

- `url: https://thebondcellar.co.za`

This is P0 because `jekyll-seo-tag`, `jekyll-sitemap`, canonical URLs, social sharing URLs, and the favicon URL depend on `site.url`.

#### 2. Fix Location Consistency in `_config.yml`

Current inconsistent fields:

- `title: The Bond Cellar - Expert in Bond Origination & Home Loans in the Durban amd KZN.`
- `description: Need help securing your home loan in Cape Town?...`

Pick one location strategy and make all site metadata consistent. Based on the saved address in `_config.yml`, use Durban/KwaZulu-Natal unless the business has intentionally moved focus to Cape Town/Western Cape.

Also fix the typo:

- `"amd"` -> `"and"`

#### 3. Add SEO Configuration Variables

Add or verify these values in `_config.yml`:

- `lang: en-ZA`
- `image: /assets/images/social-preview.jpg`
- `twitter.card: summary_large_image`

Before implementation, confirm the exact fields supported by the installed `jekyll-seo-tag` version. If global `site.image` does not produce the desired Open Graph output, add `image` front matter to high-value pages.

### Phase 2: Structured Data Enhancement

#### 4. Add Local Business Schema

Create `_includes/structured-data.html` with FinancialService schema and include it in `_includes/head.html` after `{% seo %}`.

Use `_config.yml` as the source of truth for NAP fields so metadata and visible site content do not drift. Add missing config values first:

- `telephone`
- `business_hours`, if the business wants hours public
- `same_as` social/profile URLs, if available
- `area_served`

Schema should include:

- Organization type: `FinancialService`
- Address: Shop 2, Salamanca Centre, 39 Maryvale Road, Dawncliffe, 3629
- Telephone: `+27-84-686-6089`
- Area served: Durban, KwaZulu-Natal, South Africa
- Service type: Bond Origination

Validate the generated JSON-LD with Google's Rich Results Test or Schema Markup Validator and check that it does not conflict with the JSON-LD emitted by `jekyll-seo-tag`.

#### 5. Create Social Preview Image

- Dimensions: 1200x630px
- Include: Logo + tagline "Fast bond approvals. Trusted advice. The best deals."
- Save at the path referenced by `_config.yml`
- Verify the generated `og:image` URL is absolute and uses the correct production domain

### Phase 3: Content SEO

#### 6. Optimize Page Meta Descriptions

Each calculator page needs unique, keyword-rich descriptions targeting South African bond-related searches. Add `description` front matter to:

- `bond-calculator.md`
- `affordability-calculator.md`
- `transfer-cost-calculator.md`
- `amortisation-calculator.md`
- `deposit-savings-calculator.md`
- `additional-payment-calculator.md`

Keep descriptions concise, location-consistent, and human-readable. Avoid keyword stuffing.

#### 7. Add Supporting On-Page Copy for Calculators

The calculator pages are currently mostly embedded iframes. Add concise, original helper copy above or below each iframe so the page has indexable content that matches its metadata.

Suggested content per calculator:

- What the calculator helps estimate
- Who should use it
- One short South African home loan context note
- A clear contact or pre-approval next step

#### 8. Add FAQ Schema for Calculators

Add FAQ structured data only where matching FAQ content is visibly present on the page. Keep answers specific to South African home loans and avoid duplicating the same FAQ block across every calculator page.

### Phase 4: Technical SEO

#### 9. Add robots.txt Improvements

- Add sitemap reference
- Allow all crawling

Example:

```txt
User-agent: *
Allow: /

Sitemap: https://thebondcellar.co.za/sitemap.xml
```

#### 10. Add Breadcrumb Schema

Add breadcrumb schema for calculator pages if the site exposes a clear hierarchy such as:

- Home
- Calculators
- Bond Calculator

If the visible navigation does not support that hierarchy yet, add visible breadcrumb UI first or skip this task.

#### 11. Verify Generated Output

After implementation, build the site and inspect generated HTML for:

- Correct canonical domain
- Correct Open Graph image URL
- Unique meta descriptions
- Valid JSON-LD
- Sitemap URLs using the production domain

Do not spend time adding sitemap `priority` or `changefreq`; Google ignores those values. Focus on canonical URLs, accurate `lastmod` values where useful, and submitting the sitemap in Search Console.
