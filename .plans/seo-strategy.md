# SEO Strategy & Implementation Plan

## Executive Summary

The Bond Cellar site uses `jekyll-seo-tag` for basic SEO but lacks advanced optimizations. This plan outlines improvements for search visibility in the South African home loan market.

---

## Current SEO State Analysis

### What's Working ✓
- **jekyll-seo-tag plugin** configured and generating meta tags
- **Meta viewport** set correctly for mobile
- **Canonical URLs** auto-generated by SEO plugin
- **Sitemap.xml** created and complete
- **Structured data** (WebPage schema) added automatically

### Issues Found ⚠
- **Location mismatch** in `_config.yml` - "Durban/KZN" vs "Cape Town/Western Cape"
- **No custom OG image** - missing social sharing optimization
- **Generic descriptions** - not location-specific enough
- **No organization schema** - missing business markup
- **Local SEO** - no address/business hours structured data

---

## SEO Implementation Plan

### Phase 1: Configuration Fixes (Immediate)

#### 1. Fix Location Consistency in `_config.yml`
Current (inconsistent):
- title: The Bond Cellar - Expert in Bond Origination & Home Loans in the Durban amd KZN.
- description: Need help securing your home loan in Cape Town?...

Should align - pick one location and make consistent.

#### 2. Add SEO Configuration Variables
Add to `_config.yml`:
- lang: en-ZA
- og.image: /assets/images/social-preview.jpg (1200x630px)
- twitter.card: summary_large_image

### Phase 2: Structured Data Enhancement

#### 3. Add Local Business Schema
Create `_includes/structured-data.html` with FinancialService schema including:
- Organization type: FinancialService
- Address: Shop 2, Salamanca Centre, 39 Maryvale Road, Dawncliffe, 3629
- Telephone: +27-84-686-6089
- Area served: Durban, KwaZulu-Natal, South Africa
- Service type: Bond Origination

#### 4. Create Social Preview Image
- Dimensions: 1200×630px
- Include: Logo + tagline "Fast bond approvals. Trusted advice. The best deals."

### Phase 3: Content SEO

#### 5. Optimize Page Meta Descriptions
Each calculator page needs unique, keyword-rich descriptions targeting South African bond-related searches.

#### 6. Add FAQ Schema for Calculators
Add FAQ structured data for calculator pages (good for SERP appearance).

### Phase 4: Technical SEO

#### 7. Add robots.txt Improvements
- Add sitemap reference
- Allow all crawling

#### 8. Optimize Sitemap Priority
Add priority/changefreq to individual pages.

#### 9. Add Breadcrumb Schema
For calculator pages.
